Privacy policy

Last updated: 16 November 2026.

This is a personal automation used only by its owner, GitHub user mohdahmad787. It has no other users.

What Google data it uses

  • Google Calendar: it creates and manages events only on a secondary calendar that it created itself.
  • Google Tasks: it creates, updates and deletes the owner's own to-do items.
  • Google Colab: it runs the owner's own compute jobs.

What it does not do

  • It does not collect, sell, share or transfer anyone's data to third parties.
  • It does not use Google data for advertising or to train AI models.
  • It does not access the owner's other calendars, e-mail or files.

Storage

Access tokens are kept only on the owner's own computer and, encrypted, as secrets in the owner's private GitHub repository. Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
